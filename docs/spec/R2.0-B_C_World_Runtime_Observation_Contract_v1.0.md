R2.0-B における権威的変更点は以下のみ。

Final Statement

Chron-LLM R2.0-B/C World Runtime & Observation Contract v1.0 は、

「因果グラフ上の正史を World View として管理し、LLM 実行状態を deterministic replay 可能な観測形式へ変換する基盤」

を定義する。

R1 が Canonical Event Causality を定義し、
R2.0-B が Worldline Runtime を定義し、
R2.0-C が 外部観測可能な Snapshot Boundary を定義する。

この3層により Chron-LLM は、

Generation
   ↓
Causal Graph
   ↓
World State
   ↓
Observable Snapshot

という完全な因果実行モデルを形成する。
